saveXtension now connects your local reference library to LLM clients through MCP, with editable topics and a cleaner sidebar.

- **Local MCP server:** enable MCP in Settings, copy its URL, and use the provided setup for OpenCode v1/v2, Claude Code, Codex or VS Code. The server starts disabled and stays on this computer. No model API key or subscription is required by saveXtension.
- **Read your references:** search and paginate saves by text, account, source, topic, folder, Instagram collection and dates. Retrieve full captured metadata, captions, notes, media references and original public links. Archived saves are excluded from MCP access, including direct ID and URL lookups.
- **Organize with your LLM:** create, rename and merge local topics, update descriptions, and add/remove/replace memberships in batches. Curated memberships survive source syncs. Edit notes with conflict protection and undo recent MCP changes when their affected fields still match. Topic metadata and curated memberships survive backups and desktop imports.
- **Cleaner browsing:** X accounts appear first, followed by Chrome and Archive; Instagram and its collections appear last. The sidebar remains scrollable without a visible scrollbar. Settings is beside the logo, cards fill the grid without unnecessary gaps, and the compact sync toast expands for details and controls.

MCP provides original links and captured metadata. It does not download videos, extract frames or transcribe audio; those capabilities depend on the connected LLM’s own permitted tools. Keep saveXtension running while using its MCP server. Turning MCP off rejects further connections.

Existing saves, notes and source collections are preserved. Install through **Settings → App updates**, or quit the app and install the matching download: DMG for Apple Silicon Macs, EXE for Windows x64. The Chrome/Edge helper remains version 1.7.1.

These installers retain the current signing limitations: the Mac app has an ad-hoc signature and is not notarized; the Windows installer has no publisher signature. OS trust prompts may appear. This release is published only after both native installer builds and their desktop checks pass.
