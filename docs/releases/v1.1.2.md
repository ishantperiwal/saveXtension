Saved posts now show captured metadata while their original embeds load, with simpler account refresh and MCP setup.

- **Useful loading previews:** see the saved author, caption, available thumbnail and date while X or Instagram loads. Captured text stays visible if an embed fails, with Retry and Open original available. Images still load from their original URLs; videos are not downloaded.
- **Refresh one account:** the small circular button beside a selected sidebar account runs a quick sync without changing your usual Sync selections. A selected X handle remains the target through reconnection and permission setup. Instagram uses its current login.
- **Copy an MCP connection prompt:** Settings includes OpenCode, Claude Code, Codex and VS Code chips. Copy a prompt into your client's agent chat to configure and verify the local connection while preserving existing model/provider settings. Manual configuration remains available.
- **Collapsible Instagram collections:** use the chevron beside an Instagram handle to expand or collapse its folders. Each account remembers its own choice on this computer.
- **Consistent card widths:** a single archived post or search result keeps the normal grid width instead of stretching across the page.

Existing saves, notes, topics and source collections are preserved. The Chrome/Edge helper remains version 1.7.1.

Update through **Settings → App updates**, or quit saveXtension and install the matching download: DMG for Apple Silicon Macs, EXE for Windows x64. On Mac, drag the replacement into Applications and reopen it. Reloading an older installed version does not load these changes.

The signing status is unchanged: the Mac app has an ad-hoc signature and is not notarized; the Windows installer has no publisher signature. This release publishes after both native builds and their desktop checks pass.
