saveXtension now runs as a desktop app, with GitHub updates in Settings and a fix for empty Instagram collections.

- **App updates:** the installed app checks GitHub on opening, downloads a newer stable installer for your computer, shows progress, and verifies the download. Settings also has **Check for updates**. Choose **Install version…** when ready; finish or stop any sync first.
- **Instagram collections:** recognizes creator-prefixed post and Reel links, so quick and manual deep scans attach existing saves to their original collections without duplicating posts.
- **Desktop startup:** opens the library and quick-syncs your configured accounts. Deep scans remain manual. Saves and notes stay outside the installed app and survive replacement.

Install **v1.0.1 manually once**: older builds do not contain the update control. On Apple Silicon Macs, open the DMG, quit the old app, and drag saveXtension into Applications to replace it. On Windows x64, run the EXE installer. Then open the app. The bundled Chrome/Edge helper is version 1.7.1; if prompted, reload the existing helper from its extensions page.

These are test installers. The Mac app has an ad-hoc signature and is not notarized; the Windows installer has no publisher signature. OS trust prompts may appear. Downloading an update is automatic, while installation still uses the normal installer flow. Both native platforms must pass the desktop launch/sync/persistence and packaged-app checks before this release is published.
